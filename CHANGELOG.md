# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Release headings use the current tags and original publication dates.

## [Unreleased]

### Changed

- Documented historical preview releases and streamlined contribution guidance.

## [v1.0.0-preview.20260915.1] - 2026-09-15

### Added

- A compiled Razor theme project and explicit tag list and tag detail views.
- Repository contribution, support, security, ownership, funding, and
  Dependabot configuration based on the current theme template.

### Changed

- Restored ScissorHands.NET packages from NuGet.org with centralized versions.
- Moved the preview application to the template-standard `sample` directory.
- Updated navigation, theme URL helpers, colour preference handling, and
  adjacent-page navigation for the latest engine contracts.
- Resolved the pushed tag's version explicitly in the release job.
- Updated artifact upload/download and GitHub Pages actions.

## [v1.0.0-preview.20260102.1] - 2026-01-02

### Added

- A 404 view with support for custom content.

### Changed

- Shared layout context through cascading parameters for components and plugins.
- Used the page locale for the HTML language and optional footer URL prefix.

## [v1.0.0-preview.20251226.2] - 2025-12-26

### Changed

- Used page-specific titles and descriptions in document metadata.

## [v1.0.0-preview.20251226.1] - 2025-12-26

### Added

- An empty state when no posts are available.
- PowerShell and Bash scripts for GitHub authentication and environment setup.

### Changed

- Aligned the title metadata with the computed site title.

## [v1.0.0-preview.20251221.2] - 2025-12-21

### Changed

- Rendered the computed site title with Razor encoding in the document title.

## [v1.0.0-preview.20251221.1] - 2025-12-21

### Added

- Open Graph plugin integration and sample social images.

## [v1.0.0-preview.20251216.1] - 2025-12-16

### Added

- Google Analytics plugin integration and release workflow configuration.

## [v1.0.0-preview.20251215.1] - 2025-12-15

### Added

- Initial Minimal Blog theme and release workflow.
